# agent-home

1. `git clone git@github.com:ATConstantino-apps/agent-home.git ~/agent-home && cd ~/agent-home`
2. `./scripts/clone-all.sh` (HTTPS default; `./scripts/clone-all.sh --ssh` if you use SSH keys)
3. Open Claude Code or Cursor **in `~/agent-home`**, not inside a single project.
4. Work in `repos/<name>` (gitignored). Commit in that project repo; never commit project code here.
5. Shared skills: `skills/`. Wiki: `wiki/`. Map and standing rules: `AGENTS.md`.
