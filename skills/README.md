# skills/

Skills shared across every project in this home repo. One folder per skill, with a `SKILL.md` (YAML frontmatter `name` + `description`, then the steps).

Project-local skills stay in that project. If a skill is useful in more than one repo, put it here.

| Skill | When to use |
|-------|-------------|
| [new-project](new-project/SKILL.md) | Adding a GitHub repo to the home (manifest, clone, map row) |
